# aeon

aeonプロジェクトは、イオンのウェブサイトからイオングループ企業の情報を取得し、表示するウェブアプリケーションです。

## デモ
https://code4fukui.github.io/aeon/aeon-company.html

## 機能
- イオンのウェブサイトからイオングループ企業の情報をスクレイピングして表示
- グループ内の特定の企業を見つけるための検索インターフェースを提供

## 使い方
1. `scrape.js` スクリプトを実行して最新の企業データを取得し、`aeon-company.csv` に保存します。
2. ウェブブラウザで `aeon-group2.html` ファイルを開き、検索インターフェースにアクセスします。

## データ / API
本プロジェクトは、イオンの企業ウェブサイト（ https://www.aeon.info/company/group/ ）からデータを取得します。
